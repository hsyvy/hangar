Built for the way you actually run servers.

No daemon, no config files, no YAML. Register a command and go.

One home for every server

Register a name, directory, command, and env vars once. Start and stop each server with a single click.

Live logs, per server

stdout and stderr stream straight into the app. No terminal tabs to hunt through when something breaks.

Clean shutdown

Stopping a server kills its whole process tree. No orphaned node or vite processes squatting on your ports.

URL auto-detect

Hangar spots localhost:PORT in your log output and gives you a button to open it in the browser.

Your real shell

Commands run through your login shell, so nvm, pyenv, and your PATH resolve exactly like in Terminal.

Right in the menu bar

Glance at every server's status and toggle them from the menu bar — no need to bring the main window forward.

Three steps.

From a fresh install to a running server in under a minute.

Register

Point Hangar at a folder and give it the command you'd normally type — npm run dev, python app.py, cargo run.

Run

Hit start. Logs stream in live, and Hangar surfaces the localhost URL the moment your server prints it.

Quit clean

Stop one server, or quit Hangar entirely — every process it launched is terminated with it. No leftovers.
